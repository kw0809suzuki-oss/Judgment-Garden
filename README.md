# Judgment Garden

A separate playground for growing a judgment model from evidence.

The model's memory and life-cycle history live in Google Drive. This repository is its isolated execution body.

## Current boundary

- Separate from the existing Kaggriculture Combat Model.
- Separate from Astra and the existing Semantic Kernel experiments.
- No automatic inheritance from those systems.
- Existing projects may be inspected as reference evidence, but are not modified from here.
- Unknown stays unknown.
- Action existence does not imply an intervention exists.
- A semantic pass does not imply strategy improvement.

## First body

The first target is deliberately small: support the precommitted Blind Test 001 without touching the existing Kaggriculture implementation.

Comparison:

1. Closure-only control
2. Closure + HIRE-stop-only
3. Closure + early-HARVEST-only

The repository should first build an isolated intervention representation and trace contract. Battle integration comes only after that boundary is explicit.
